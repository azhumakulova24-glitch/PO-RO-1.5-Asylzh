# Restaurant Database Project

## 📌 Domain Description
This project represents a relational database system for a restaurant management system.  
It models core business processes such as staff management, table reservations, menu handling, orders, and shift scheduling.

The database is designed to simulate real-world restaurant operations in Atyrau and supports realistic workflows such as order processing, staff assignment, and menu pricing.

---

## 🗄️ Database and Schema Names

- **Database name:** `restaurant_db`
- **Schema name:** `restaurant`

All tables and relationships are created within the `restaurant` schema to ensure logical separation and modular structure.

---

## ⚙️ How to Run the Project

1. Open **pgAdmin / DBeaver**
2. Connect to PostgreSQL server
3. Create database:
   ```sql
   create database restaurant_db;
